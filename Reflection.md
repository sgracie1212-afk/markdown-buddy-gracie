# Reflection – BDA400 Assignment 1

For this assignment, I used ChatGPT to help me create documentation for my Student Grades Analysis project. It helped me organize my README file, understand Markdown formatting, and write explanations for my R code.

At first, I was not familiar with creating documentation on GitHub. ChatGPT guided me through the steps, and I made changes as I worked.

I learned how to create files, use headings, add code examples, and save my work on GitHub. I also learned that AI can make assignments easier, but I still need to review the information and check that everything is correct.

Overall, this assignment helped me become more comfortable using GitHub, Markdown, and AI tools for documenting a data analysis project.
